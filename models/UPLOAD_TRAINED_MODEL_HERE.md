# Deploy your student-trained CircuitVision detector

The CircuitVision notebook has already produced a trained **YOLO11n** detection
checkpoint from the two electronics datasets.

## How to install it

1. Sign in to the project's GitHub repository.
2. Open the models folder, then use **Add file -> Upload files**.
3. Upload the *original*, unmodified **CircuitVision_Trained_Model.zip**
   generated by Google Colab. **Keep this ZIP file zipped.**
4. Commit directly to the main branch.
5. Render redeploys the connected free service; the backend installs
   best.onnx and classes.json automatically after checking the ZIP's
   SHA-256 against the file that was inspected in ChatGPT.

Direct upload page:
https://github.com/aquinogeraldedmiranda-art/CircuitVision-YOLO/upload/main/models

The notebook ZIP is 14.3 MB and within GitHub's web upload limit. Do not upload
best.pt separately; the website only needs the CPU-compatible best.onnx.
If a file with the same name already exists, contact the project maintainer.

Once deployed, check the health endpoint:

https://circuitvision-yolo-lab.onrender.com/api/health

Expected: "custom_model_available": true,
"model_file": "best.onnx", "class_count": 57.

For accuracy, this is the first YOLO11n quick run, not the final larger
YOLO11s run. The measured test mAP@50 was 0.3966; LDR and Power Module
classes had weak test performance. Improvement will require more examples.
